# 当前 MVP 范围

当前系统定位为：外派员工宿舍、人员停留、入住分配、车辆基础档案管理系统。

当前交付阶段为内部试用版，支持系统账号密码登录和基础权限控制。权限当前仅区分 `admin` / `user`，角色设计保留未来扩展空间。

当前版本：`v0.7-mysql-deployment-prep`。本阶段新增 SQLite / MySQL 配置切换、本地虚拟服务器部署准备、备份建议和 admin-only 系统信息页。

## Included

- 宿舍档案、租期和状态维护
- 房间档案、床位、性别限制和状态维护
- 人员基础档案、部门、人员类型和性别维护
- 签证与停留作为人员的附属合规信息维护，数据表保持独立
- `/stay` 主导航定位为停留风险清单，用于处理 30 天内到期、60 天内到期、已超期、未维护最大停留日期
- 入住分配与退宿
- 车辆基础档案和车辆状态维护
- 保险到期、年检到期、保养到期提醒
- 字典维护
- 用户登录、用户管理、admin / user 权限控制
- SQLite 开发模式与 MySQL Community Edition 试用部署支持
- System 页面，仅 admin 可见，用于查看版本、数据库类型、系统环境和当前用户
- Dashboard 统计
- 审计日志接口，operator 记录当前登录用户名
